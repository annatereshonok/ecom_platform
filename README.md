# Ecom-platform

## Описание проекта
В этом репозитории будет собран проект, посвящённый использованию классов и объектов в контексте e-commerce (электронной коммерции). В рамках работы мы создадим основу для интернет-магазина, которая будет включать в себя базовые компоненты системы, такие как товары, заказы и пользователи. На текущем этапе реализации не предусмотрена интеграция с платёжными системами, однако подготовлены все необходимые структуры, которые в будущем можно будет расширить для реализации различных интерфейсов, например, веб-сайта или телеграм-бота.

## Классы
### `BaseProduct` (абстрактный класс)
Базовый абстрактный класс, от которого наследуются все продукты (например, `Product`, `Smartphone`, `LawnGrass`).

Атрибуты:
- `name` (str) — название продукта
- `description` (str) — описание
- `price` (float / int) — цена (не может быть отрицательной)
- `quantity` (int) — количество на складе

Особенности:
- защита от установки некорректной цены (через @property)
- логика подтверждения при снижении цены

### `MixinLog`
Класс-миксин, предназначенный для логирования информации при создании объекта.

Поведение:

При создании объекта с использованием MixinLog автоматически выводится сообщение в консоль:

```sh
[LOG] Создан объект класса Product с аргументами: ('Название', 'Описание', 1000, 5), {}
```

### `Product`
Класс-наследник BaseProduct для описания смартфонов.

Особенности:
- перегруженный метод __add__ — сложение доступно только для одинаковых классов
- метод new_product — создание объекта из словаря с объединением количества и максимальной ценой, если такой уже есть

### `Smartphone(Product)`
Класс-наследник Product для описания смартфонов.

Доп. атрибуты:
-`model` (str) — модель
- `memory` (int) — объем памяти
- `color` (str) — цвет
- `efficiency` (float) — энергоэффективность

### `LawnGrass(Product)`

Класс-наследник Product для описания газонной травы.

Доп. атрибуты:
- `country` (str) — страна-производитель
- `germination_period` (float) — период прорастания в днях
- `color` (str) — цвет травы

### Category

Класс категории продуктов. Хранит список объектов продуктов.

Атрибуты:
- `name` (str) — название категории
- `description` (str) — описание категории
- `products` (List[Product]) — список продуктов

Атрибуты класса:
`category_count` (int) — количество созданных категорий
`product_count` (int) — общее количество всех продуктов во всех категориях

Особенности:
- метод `add_product(product)` — добавляет только объекты Product или его наследников, иначе выбрасывает TypeError
- `@property products` возвращает красиво отформатированный список строк

## Тестирование

Этот проект использует `pytest` для написания и запуска тестов.


## Запуск тестов

Для запуска всех тестов выполните следующую команду:

```sh
pytest
```

## Покрытие кода тестами

Для проверки покрытия кода тестами можно использовать `pytest-cov`:

```sh
pytest --cov=src
```

Где `src` — папка с исходным кодом.

## Логирование и отчеты

Для генерации HTML-отчёта о покрытии выполните:

```sh
pytest --cov=src --cov-report=html
```
